# Praktikum 6 – JavaScript DOM dan Event Handling

## Latihan 1 – Manipulasi DOM

### Penjelasan
Latihan ini mempelajari cara memanipulasi elemen HTML menggunakan JavaScript DOM. Metode `getElementById()` digunakan untuk memilih elemen berdasarkan ID, sedangkan `textContent` digunakan untuk mengubah isi teks.

### Hasil Praktikum
Judul dan pesan pada halaman web berhasil diubah menggunakan JavaScript.

![Hasil Latihan 1](./ss/Screenshot%202026-10-28%20092224.png)

---

## Latihan 2 – Event Handling

### Penjelasan
Latihan ini mempelajari penggunaan event handling dengan `addEventListener()`. Event `click` digunakan untuk menjalankan fungsi ketika pengguna menekan tombol.

### Hasil Praktikum
Ketika tombol ditekan, teks pada halaman berubah dan waktu saat tombol diklik ditampilkan.

![Hasil Latihan 2](./ss/Screenshot%202026-10-28%20092314.png)

---

## Latihan 3 – Manipulasi CSS

### Penjelasan
Latihan ini menerapkan manipulasi CSS menggunakan JavaScript. Metode `classList.toggle()` digunakan untuk menambahkan atau menghapus class CSS pada elemen HTML.

### Hasil Praktikum
Tampilan elemen berubah setelah tombol ditekan, termasuk warna teks, latar belakang, garis tepi, dan ukuran huruf.

![Hasil Latihan 3](./ss/Screenshot%202026-10-28%20092557.png)

---

## Latihan 4 – Penghitung Karakter

### Penjelasan
Latihan ini membuat penghitung karakter menggunakan event `input`. JavaScript menghitung jumlah karakter secara otomatis ketika pengguna mengetikkan teks.

### Hasil Praktikum
Jumlah karakter diperbarui secara langsung dan pengguna dibatasi hingga maksimal 40 karakter.

![Hasil Latihan 4](./ss/Screenshot%202026-10-28%20092822.png)

---

## Latihan 5 – Validasi Form

### Penjelasan
Latihan ini mempelajari validasi formulir menggunakan JavaScript. Data yang dimasukkan diperiksa berdasarkan ketentuan nama, format email, dan usia. Event `submit` digunakan untuk memproses data formulir.

### Hasil Praktikum
Sistem menampilkan pesan kesalahan ketika data tidak sesuai. Apabila data memenuhi ketentuan, sistem menampilkan pesan bahwa formulir berhasil dikirim.

![Hasil Latihan 5](./ss/Screenshot%202026-10-28%20093025.png)

## Mini Project – Form Pendaftaran Workshop

### Penjelasan
Mini project ini menggabungkan HTML, CSS, dan JavaScript untuk membuat formulir pendaftaran workshop interaktif. Fitur yang diterapkan meliputi input nama, penghitung karakter, input email, pilihan sesi workshop, ringkasan pilihan sesi, validasi formulir, dan tombol reset.

### Pengujian 1 – Validasi Gagal

Pengujian pertama dilakukan menggunakan data yang tidak memenuhi ketentuan. Sistem menampilkan pesan kesalahan sehingga pengguna dapat memperbaiki data sebelum melakukan pendaftaran.

![Mini Project - Validasi Gagal](./ss/Screenshot%202026-10-28%20093700.png)

### Pengujian 2 – Validasi Berhasil

Pengujian kedua dilakukan menggunakan data yang valid. Setelah formulir dikirim, sistem menampilkan pesan bahwa pendaftaran berhasil.

## Kesimpulan

Praktikum ini memberikan pemahaman mengenai penggunaan JavaScript DOM dan event handling untuk membangun halaman web yang interaktif. Materi yang dipelajari meliputi manipulasi elemen HTML, penanganan event, manipulasi CSS, penghitung karakter, validasi formulir, dan pengelolaan daftar tugas. Seluruh materi tersebut diterapkan kembali dalam mini project berupa Form Pendaftaran Workshop.
